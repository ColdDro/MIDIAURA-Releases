# MIDIAURA

Official download repository for MIDIAURA — a MIDI and audio visualization application by YAUPLUGINS.

**MIDIAURA LITE**
- Free

- 11 presets
- MP4 export
- No activation required

**MIDIAURA FULL**
- One-time purchase
- 25 visual worlds
- 141 presets
- MP4, MOV ProRes 4444 and PNG sequence export
